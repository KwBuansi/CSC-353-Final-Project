How to Use

  1. Create a Google Form quiz. Turn on Collect email addresses (so responses include Email Address in the CSV). Use Make this a quiz so scores are recorded.
  2. Add required questions whose titles match exactly (case-sensitive): First Name, Last Name, Student ID, Semester, Year, Course, Section. For Section, students enter only A or B (use A if the course has a single section).
  3. Enter a display title for this quiz and paste the form share link, then click Create a new QR Code.
  4. Save each quiz’s responses as a .csv under data/ (you can have several). Name each score column in the sheet after that quiz, or name the CSV file after the quiz if the score column is only called something like “Total points”. Set your MySQL password at the top of DataImporter.py, then run DataImporter.py once to update MySQL and data/grades_snapshot.json for the heatmap.
